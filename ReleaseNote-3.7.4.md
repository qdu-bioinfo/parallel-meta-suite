# Parallel-Meta Suite release note
# Version 3.7.4

# I. Function update

*A new option has been provided, now you can select PM-comp-taxa or PM-select-taxa using"-g" to achieve the log convertion of abundance, and the option is independent of " -r".
*Fixed the issue of creating databases multiple times when calling PM profiler.
*A new database has been added, now you can use -D D to select the RDP database.
*PM-parallel-meta now supports list input, use -i for single sample, -l for sample list, use -M m to specify shotgun samples or -M r for 16S samples.

# II. Others

*Fixed some bugs.
